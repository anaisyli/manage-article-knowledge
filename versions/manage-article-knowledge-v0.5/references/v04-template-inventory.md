# v0.4模板继承与替换清单

本清单用于证明v0.5对v0.4人工控制面的逐项审计。保留不等于照搬旧流程；v0.5保留可读性、追溯和治理合同，同时替换已明确废弃的全量加工与固定人工门禁。

| v0.4人工产物 | v0.5处理 | v0.5入口或替代 | 说明 |
|---|---|---|---|
| 当前待办 | 保留 | `01_工作台/20_当前待办.md` | 唯一当前任务清单，保留人话事项、责任人、入口和更新条件。 |
| 版本与变更入口 | 保留并加强 | `01_工作台/30_版本与变更入口.md` | 增加实际Skill SHA-256。 |
| Skill反馈台账 | 保留 | SKFB台账 | 保留复现、维护、项目验证和关闭条件。 |
| 项目基础信息 | 保留并加强 | `01_工作台/10_项目基础信息.md` | 恢复正式初始化字段和人工接触节点。 |
| 源文件总表 | 适配保留 | `02_源资料/源资料与可检索性台账.md` + SQLite | Markdown供人看，SQLite供机器检索。 |
| 项目基础情况/模块概览 | 适配保留 | 项目基础信息的模块入口 + 正式知识目录 | 不恢复知识完备度评分。 |
| 项目资料稿 | 合并替换 | 正式知识目录 + 当前待办 + 项目运行账本 | 不复制正式知识正文。 |
| 单文件内容导航 | 按需替换 | SQLite定位 + 命中后的精确证据定位 | 不为全部文件预生成导航。 |
| 文章要求与大纲 | 适配保留 | `10_文章知识需求.md` | 保留文章身份、大纲、语言和限制。 |
| 待提交资料清单/范围样本确认 | 废弃固定门禁 | `15_检索与知识准备记录.md` + 后台文章前审核 | 普通检索与范围收窄由Codex自动完成。 |
| 运营提交文件用途登记 | 按需吸收 | 来源台账和文章检索记录 | 同一来源只登记一次，不按文章复制。 |
| 外部调研证据 | 保留证据合同 | 正式Claim及文章知识资料 | 只在真实知识缺口触发。 |
| 源文件级清理稿/质量记录 | 按需替换 | Claim最小原文证据 + 源文规范化记录 + ANM | 不做全量清理；原文错误不静默改写。 |
| 处理结果 | 适配保留 | 检索记录、Claim、MAT详情和运行账本 | 结果必须可回到资料名、路径和来源。 |
| 文章前知识审核 | 保留 | `20_文章前知识审核.md` | 正常后台通过，真实决定才升级人工。 |
| 客户沟通卡/待客户补充总表 | 合并保留 | CUS台账 | 同一事实问题复用一个CUS。 |
| 源文与事实异常 | 保留 | ANM台账 | 保留原文现场和处置边界。 |
| 源资料处理待办 | 保留并改为归组 | MAT台账 | 一类问题一个MAT，多个文件不重复展开。 |
| 文章写作输入 | 拆分替换 | `30_本篇知识库资料.md` + `35_写作素材来源索引.md` | `30`只提供作者可用知识，`35`只保留哈希、行范围、Claim及来源的轻量映射；完整证据留在正式知识，不再复制一份审计包。 |
| 最终文章与引用率 | 替换 | `40_最终文章.md` + 外部Faithfulness导入 | 删除旧引用率字段。 |
| 文章引用/Claim使用表 | 替换 | Claim文章支撑记录CSV | 只记录可确定的事后证据映射。 |
| 非Markdown数据说明 | 保留 | `05_数据与审核/01_数据说明.md` | 链接SQLite、CSV和JSONL并说明维护边界。 |
| 知识提取与沉淀总表 | 适配保留 | 正式知识目录 + 项目运行账本 + 月度覆盖与缺口视图 | 只在文章命中后沉淀；不建立逐Claim重复台账。 |
| 正式知识目录与稳定实体文件 | 保留并轻量化 | `03_正式知识/` | 恢复七模块导航，不创建空知识正文，不评分。 |
| 产品主数据/服务政策/动态快照 | 按需保留模式 | 对应稳定实体或主题文件 | 只有真实复用需求时创建。 |
| 月度维护简报 | 保留框架 | 月度知识库审核 | 保留五部分，Faithfulness替代旧引用率。 |
| 项目交接审核 | 保留 | 项目交接审核 | 保留路径、负责人、四类事项和结论。 |

发布前必须同时检查本清单、[人工可读控制项规范](human-readable-control-artifacts.md)和[v0.4稳定性兼容清单](v04-stability-compatibility.md)。
