## 1. 使用原则

- 优先使用原文件可靠文本层和格式专用读取能力。
- 工具输出是派生结果，不是独立事实来源。
- 任何工具都不能免除来源定位、内容指纹、样例验证和高风险抽查。
- 不把一个工具设为所有文件的永久唯一方法。
- 记录工具、版本、参数、输入范围、输出格式和已知限制。
- 工具或服务能力、许可证和价格可能变化，实施前重新核对官方说明。

## 2. 文档与Office资料

### Office容器只读检查

在读取DOCX、PPTX、XLSX或ZIP可见正文前，运行：

```powershell
python scripts/inspect_office_container.py "资料文件.docx"
```

脚本只列出嵌入对象、媒体、图表、关系、候选原文件名、载荷签名和未识别对象，不写出或修改文件。`unresolved_embedded_object_count`不为0时，必须把对象登记为异常并继续人工/工具核验；`ready_for_content_processing`只表示扫描器没有未识别嵌入项，不代表内容准确、完整或已获准处理。

### 原生读取

优先用于：

- DOCX标题、段落和表格；
- PPTX幻灯片、文本框和备注；
- XLSX工作表、单元格、公式和表头；
- 带可靠文本层的PDF。

复杂版面、扫描页、图表、流程图、复杂表格和关键嵌入图片仍需视觉或OCR核验；纯装饰图不进入正文，但不得以“无连续文字”跳过关键视觉关系。

### MinerU等可选解析工具

MinerU是内容运营生成范围内PDF/PPT Markdown稿的推荐工具，但不形成独立Obsidian目录；稿件统一归入`运营提交`。PPT必要时可先固定为PDF。Codex仍结合原文件和其他工具复核。实际使用时记录：

- MinerU版本、后端和参数；
- 原文件版本；
- 覆盖页数；
- 页码映射；
- 表格和跨页内容情况；
- OCR或阅读顺序异常；
- 稿件归属（Codex提取或运营提交）以及对应核验状态。

MinerU用于降低重复解析成本，不代表原文件已被完整、逐字、结构无误地还原。重要数字、图表、型号和页面关系仍回看原文件。

### 其他候选

根据环境和授权，可评估格式原生解析、MarkItDown、Docling或其他本地工具。轻量Markdown转换适合结构扫描和普通文本，不等于高保真版式还原；结构化JSON也不等于逐字无误。

## 3. OCR与扫描资料

可以使用PaddleOCR或环境中经过验证的OCR能力。复杂资料优先：

```text
可靠文本层
→ 版面解析
→ 只对缺失区域OCR
→ 页面视觉核验
```

不要对已有可靠文本层的全部页面重复OCR。OCR结果先标记`ocr-verbatim`；低质量扫描、数字、型号、单位、印章、手写和罕见术语必须抽查。

## 4. 音视频

内容运营负责选择公司允许的转写方式并提供原始逐句稿、字幕稿或转写稿。可以使用Whisper或其他工具，但必须记录：

- 工具和版本；
- 文件与时间范围；
- 是否上传外部服务；
- 语言；
- 时间码；
- 运营初检；
- 产品型号、人名、数字、单位、术语和重叠说话异常。

已有官方字幕时优先使用并抽样核对，不重复全量转写。Codex收到后先原样保存，再建立清理、翻译或证据稿。

## 5. 网页与外部调研

- 已知客户官网页面时自动定位和提取，不让运营从零搜索。
- 公开网页优先记录直达URL、页面身份、发布/更新日期和获取日期。
- 登录、付费墙、反爬或正文不完整时，不绕过限制；请求Web Clipper稿、下载文件或可见正文。
- 外部调研的网页/文章必须保存可取得的原文证据文件和独立整理文件，不能只留下链接或Codex摘要。
- 搜索结果、AI回答和聚合摘要只能用于找来源，不能作为正式知识。
- 关键词或SEO数据必须记录供应商、地区、语言、查询日期和字段定义；没有确定数据源时不虚构搜索量。
- 动态市场、趋势和消费者数据优先使用较新资料；旧资料只在标准、法规、基础研究或历史背景仍有效时使用，并明确日期。

## 6. 保密与外传

客户保密资料优先本地处理。使用线上API或外部平台前确认：

- 是否允许上传；
- 数据保留和训练使用；
- 服务地区；
- 访问控制；
- 账号和下载权限；
- 输出能否长期保存和审计。

没有授权时使用本地工具或请运营在合规环境生成提取稿。只授予任务所需最小文件范围。

## 7. 代表性样例验证

工具投入正式流程前，用小测试集验证：

- 普通文本PDF；
- 扫描PDF；
- 多栏或跨页PDF；
- 简单表格和多层表头；
- 大型Excel；
- 带文字的图表、流程图和图片；
- 中英文混合、型号和单位；
- 视频或音频；
- 损坏、缺页或异常文件。

记录：

| 项目 | 内容 |
|---|---|
| 工具与版本 | 实际版本、参数和运行方式 |
| 文件类型 | 测试样例 |
| 原文准确性 | 漏字、错字、乱序 |
| 定位能力 | 页码、坐标、单元格、时间码 |
| 结构保留 | 标题、表格、图表、含文字图片 |
| 运行成本 | 时间、Token、CPU/GPU、API费用 |
| 数据边界 | 本地或外传 |
| 人工复核量 | 比例和高风险项 |
| 结论 | 推荐、条件使用或淘汰 |

只有通过代表性样例的工具组合才进入正式处理。
